# 🌱 GREENBITE — Food Waste to Food Share

> **Transforming Food Waste into Hope**  
> GREENBITE is a web platform designed to bridge the gap between cloud kitchens, restaurants, and surplus food donors with local verified NGOs and community delivery partners.

---

## 🚀 Live Demo

- **Hosted on Vercel:** [https://greenbitefoodshareconnect.vercel.app/]
- **GitHub Repository:** [https://github.com/shreyaverse-io/Greenbite-foodshare-connect](https://github.com/shreyaverse-io/Greenbite-foodshare-connect)

---

## ✨ Features

- **Single Page View Routing:** Fast client-side navigation between Home, Contact Us, and Join Us sections without full page reloads.
- **Interactive Role Onboarding:** Customized modal forms tailored specifically for:
  - **Donors:** Report surplus meals, pickup time windows, and portion quantities.
  - **NGOs:** Share daily receiving capacity and service area details.
  - **Delivery Partners:** Register vehicle type and availability to earn while serving the community.
- **Dynamic FAQ Accordions:** Expandable answers for quick onboarding and common questions.
- **Impact Metrics:** Animated statistics counter showcasing total meals delivered, partner restaurants, and food waste saved.
- **Responsive & Lightweight:** Pure HTML, CSS, and vanilla JavaScript design optimized for mobile and desktop screens.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Icons & Theme:** Emoji-based design with vibrant green/purple gradients
- **Deployment:** Vercel (Single-file static deployment)
